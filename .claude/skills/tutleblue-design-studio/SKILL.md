# 디자인 스튜디오 (시작 스킬)

이 스킬은 짧다. 실제 절차는 도구와 함께 오는 안내서(`GUIDE.md`)에 있다. 도구가 바뀌면 안내서도 함께 바뀐다.

## 1. 도구 받기

- 위치: 환경 변수 `STUDIO_HOME` 이 있으면 그곳, 없으면 `~/.claude/design-studio/tool`
  (Windows: `%USERPROFILE%\.claude\design-studio\tool`).
- 없으면 받는다:
  ```
  git clone --depth 1 https://github.com/tutleblue/claude-code-designtool <위치>
  ```
- 있으면 새로 받는다: `git -C <위치> pull --ff-only`. 실패하면(네트워크, 로컬 변경) 그 판 그대로 쓰고 사용자에게 한 줄로 알린다. 로컬 변경은 지우지 않는다.
- git 이 없거나 받을 수 없으면 사용자에게 위 명령을 직접 돌려 달라고 한다.

## 2. 안내서 따르기

`<위치>/skill/GUIDE.md` 를 읽고, 사용자가 원하는 일에 맞는 절로 간다.

| 사용자가 원하는 것 | 절 |
|---|---|
| 처음 쓰기, "이 앱에 맞춰 줘", 앱 구조가 크게 바뀜 | 1. 개인화 |
| "스튜디오 열어 줘", 화면을 직접 만져 보고 싶다 | 2. 열기 |
| 문서·보고서·발표 자료·표·그림·PDF 같은 **작업물**에 댓글 달고 고치고 싶다 (개인화 필요 없음) | 2-1. 작업물 열기 |
| "저장본 반영해 줘", "만져 본 대로 바꿔 줘" | 3. 저장본 반영 |
| 스튜디오가 `claude -p` 로 너를 띄움 (프롬프트에 '시안') | 4. 시안 모드 |
| "시안 ○○ 반영해 줘", "충돌 정리해 줘" | 4. 시안 모드 끝부분 |
| "스튜디오 업데이트", 도구가 이상함 | 5. 업데이트 |

웹 앱을 다루는데 개인화 설정(`<앱 저장소>/.claude/design-studio/studio.app.json`)이 아직 없으면 먼저 **1. 개인화**를 한다. 작업물(파일·폴더)은 개인화 없이 바로 **2-1**.
